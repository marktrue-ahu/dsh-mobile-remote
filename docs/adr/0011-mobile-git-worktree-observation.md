# 0011 移动端 Git 工作区观察仍保持只读

状态：已接受

移动端 Git 只读浏览增加当前工作区情况与按文件差异预览，但不增加任何 Git 写操作。为适应分支列表、分支图、工作区及未来视图，入口使用全屏浏览页和最多三个可配置、有序 Tab；差异仅在用户选中已授权仓库中的具体文件时按需读取，严格限制输出并将二进制、冲突等不可安全呈现的对象标为非文本状态，工作区变化提示显式刷新。此决策仅取代 ADR 0009 中“不可查看 status/diff”和“使用可拖动抽屉”的条款，其余会话授权、只读图谱、tip 绑定快照、分页与安全约束继续有效；选择此方案，是在保留手机端代码审阅能力的同时，避免暂存、提交等写操作及无界仓库补丁读取扩大权限与隐私风险。
