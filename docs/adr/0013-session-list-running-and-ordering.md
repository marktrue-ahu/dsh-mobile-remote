# 0013 会话列表按最新消息时间排序，隐藏子代理会话，图标区分运行与等待

状态：已接受

移动端会话列表此前按插件合成的 `lastActivity` 排序，而该时间由**任意** live 事件与手机端「打开会话」共同推高，导致单纯查看会话就会改变列表顺序，且无法解释为「最近有消息」。本次改为以**最新消息时间**（`lastMessageAt`）为排序键，打开会话不再触碰排序；同时新增 `origin`/`parentSession` 字段，客户端隐藏 `origin === 'subagent'` 的子代理会话；会话图标在 `running` 时显示方形虚线循环旋转动效。

选择新增 `lastMessageAt` 而非改变 `lastActivity` 语义，是为了让旧版 App 行为完全不变；选择在客户端过滤子代理会话而非服务端排除，是为了让旧版 App 仍看到完整列表。排序回退 `lastActivity` 再回退 `createdAt`，插件的 `touch` 端点保留给旧版 App。

判断子代理会话只认内核 `origin === 'subagent'`，**不认** `parentSession`——用户主动 fork 的会话只有 `parentSession` 而没有 `origin`，按父会话判定会误伤。

会话图标分两种状态标识：`running` 显示旋转虚线，等待用户审批/作答显示**静态虚线加警示色**（不旋转，因为会话在等答复而不是在推进）。内核 `AgentStatus` 是 `idle | running` 二元联合，**不存在 `waiting`**；等待用户这件事由挂起的问询/审批独立承载。这修正了 App 与文档长期沿用的三值假设（`waiting` 是 v2.1 起的防御性猜测，内核从未产生过该值）。系统「减弱动态效果」开启时旋转降级为静态虚线，状态本身必须可见。
