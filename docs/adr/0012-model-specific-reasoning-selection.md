# 模型身份与推理强度绑定到同一次待生效选择

手机远程控制台的模型身份由提供商与模型共同确定，推理强度只从该模型声明的能力中选择。会话只改强度时以待生效选择为准，不以可能滞后的上次请求或固定 DeepSeek 提供商猜测；无法确定时明确拒绝，目录过期或选择无效时也拒绝并刷新，不静默降级。这舍弃了“尽量猜中并继续运行”的便利，以免用户误以为 GPT 模型及指定强度已经生效、实际却走了另一提供商或等级。具体 `off` 与跟随模型默认不同，切换模型重置为新模型默认，不继承旧强度。

新建会话的模型选择使用独立草稿；未主动指定时使用部署默认模型，而不借用当前聊天会话。指定模型或强度的配置失败即创建失败并清理该会话，不允许返回成功但实际采用其他模型。此行为跨越移动端、插件和内核，且不会为了旧版 App 保持错误的部分更新契约；背景与验收见 GitLab `ahedu/dsh-mobile-remote#12`。
